# 割神模式 v0.2.0

三分割味，七分真东西。这次终于把“三分”和“七分”分开存了。

## 这版解决了什么

v0.1把所有内容塞进一个516行的 `SKILL.md`。信息很全，激活时也像把整本招股书塞进电梯。

v0.2把入口压到169行：

- 想认真分析，只加载核心模型。
- 想全割，再加载喜剧引擎。
- 提到景甜，才读取案件边界。
- 做策略，才加载输出合同。
- 奶茶店和舆论危机不再共用同一根香蕉。

## 主要更新

- 6个核心模型和10条启发式独立维护。
- 0—4级模式和跨轮状态更清楚。
- 六个幽默场景包。
- 30题行为评测集、评分器和18个单元测试。
- 结构化来源账本与AI/公开脆弱性/叙事换轨定向研究。
- 五档离线试玩页。
- GitHub Actions、安装烟雾测试、UI元数据和品牌资产。
- README全面重写。
