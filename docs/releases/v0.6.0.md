# 割神模式（孙宇晨Skill）v0.6.0

灯关了，采访麦还亮着。

v0.6.0把这个看似像段子的反差，变成了一套可以复用的专业检查方法：一个人宣布“停止回应”时，先问他停止了什么、在哪个渠道停止、谁还在发声，以及现实程序是否真的结束。

## 最新事件增量

- 纳入2026年9月6日采访、9月7日公开的新节点。
- 记录孙宇晨在采访中对款项性质、和解通道与后续披露边界的公开说法。
- 保持案件仍处管辖权异议审查、尚未实体审理的程序边界。
- 采访只能证明他说过什么，不证明其诉讼主张成立。

## Skill深化

新增“叙事退出四问”：

1. 退出的是哪个对象？
2. 退出的是哪个渠道？
3. 哪个主体退出，谁还在发声？
4. 司法、监管或交易程序是否变化？

默认交付也更清晰：一句判断、模型与因果链、三步动作、转化指标、代价与止损，最后才允许出现一记割味。
