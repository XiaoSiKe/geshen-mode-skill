# 割神模式 v0.4.0

这次不发布网站，只发布Skill。

## 定位纠正

v0.3加入了Web页面和运行时JS。它们可以运行，但不属于这个项目的核心职责。v0.4全部移除：

- 没有Web页面；
- 没有浏览器应用；
- 没有运行时JS；
- 安装包没有CI、测试或开发工具。

留下的是 `SKILL.md`、UI元数据、图标、模型、协议、案例和调研。

## 深化内容

- 事实研究协议：来源优先级、证据卡、时效、冲突、引语和失败降级。
- 七类回答配方：不同问题使用不同最低交付。
- 100分质量量表与一票否决。
- 40题Skill行为评测。
- 前向评测批次生成器和JSONL回答格式。
- 纯Skill确定性安装包。
- README压缩为简洁、专业、有梗的项目介绍。

## 保留

- 6个核心模型。
- 10条决策启发式。
- 0—4级割味。
- 六个幽默场景包。
- 景甜事件四层事实边界。

## 安装

```bash
npx skills add XiaoSiKe/geshen-mode-skill
```

也可以下载本Release的 `geshen-mode-v0.4.0.zip`。

三分割味，七分真东西。现在连安装包也是。
