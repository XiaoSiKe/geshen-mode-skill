# 割神模式 v0.5.0

这次没有增加新功能，重点是把话说准。

## 新定位

割神模式现在定义为：

> 孙宇晨式注意力策略、叙事工程与高风险决策框架

它基于7份调研底稿、2489行材料、6个心智模型和10条决策启发式，服务于产品发布、内容营销、品牌定位、危机沟通、创业决策和策略复盘。
