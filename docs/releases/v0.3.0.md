# 割神模式 v0.3.0

v0.2让Skill学会少读一点，v0.3让规则真的跑起来。

## 这版最重要的变化

试玩页新增共享 `core.js`。模式状态、安全降级、场景识别、数字锚点和输出结构只有一个执行所有者：

- 浏览器调用它；
- Node测试调用它；
- 运行时评测也调用它。

文档不再单方面宣布“退出会持续”。现在测试会追着它再问一轮。

## 新增验证

- 12个Node核心测试。
- 17组多轮运行时评测。
- 162项运行断言。
- 确定性Release压缩包与内容验证。
- 外部事实离线降级测试。
- 用户题设数字保留测试。
