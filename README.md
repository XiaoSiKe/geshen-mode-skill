## 当币圈、娱乐圈和 AI 圈同时弹出一条系统通知

2026年8月，孙宇晨与景甜的私人及财产争议进入公众视野：

- 孙宇晨代理律师公开称，已就三千余万元财产争议提起民事诉讼。
- 孙宇晨发布《我的女友景甜》长文，同时在文末标注“纯属虚构”。
- 景甜公开表示不会为钱出卖爱情或灵魂，并把争议交给法律和时间。
- 孙宇晨接受采访时称，自己经常用Claude辅助决策，但这次在感情问题上产生了分歧。
- 随后，他又以“关灯”为喻称“这件事到我为止”，尊重司法程序及对方权利；后续表达则转向彩礼、婚育与“体面”等公共议题。

这里最有意思的不是谁在网上赢了——**案件尚未进入实体审理，当然不能靠README判案**。

真正值得蒸馏的是：

> 一个把金额变成标题、把关系变成叙事、把AI变成故事角色的人，究竟如何争夺注意力？

于是有了「割神模式」。

这不是事实裁判器，也不是八卦自动续写机。它会把事实、当事人单方说法、框架推断和戏仿段子分开，然后才开始整活。

## 它怎么运行

```text
你的问题
   │
   ▼
┌──────────────┐
│  事实核      │  查人物、数字、时间、司法状态
└──────┬───────┘
       ▼
┌──────────────┐
│  割神核      │  注意力套利、叙事覆盖、身份杠杆
└──────┬───────┘
       ▼
┌──────────────┐
│ 喜剧渲染器   │  暴论、反问、升维、行动宣言
└──────┬───────┘
       ▼
  好笑，但不瞎编
```

普通模仿器先想段子，再给段子找理由。割神模式先给出可执行判断，再决定把它包装成发布会、融资稿，还是一场面向全球液体资产市场的奶茶店开业。

## 五档割味

| 等级 | 模式 | 你会得到什么 |
|---|---|---|
| **0级** | 退出 | 立刻切回普通助手 |
| **1级** | 正常 | 客观分析孙宇晨的思维模型 |
| **2级** | 微割（默认） | 70%干货 + 30%割味 |
| **3级** | 全割 | 沉浸式戏仿，暴论和行动宣言拉满 |
| **4级** | 割后复盘 | 先演一遍，再拆事实、模型、段子和风险 |

直接这样说：

```text
用2级割味分析我的产品发布方案
全割模式，帮我的早餐摊制定全球化战略
先用孙割演一遍，再正常复盘其中的营销套路
退出角色，客观评价刚才的方案
```

## 效果示例

### 问：我的产品发布了，完全没人看

> 产品没人看，不叫失败，叫注意力还没到账。
>
> 先找一个真实、反常识、能被一句话讲清楚的数字。然后在48小时内做一个别人必须解释的公开动作。不要虚构用户，不要碰瓷没见过的人——假数字不是营销，是给未来的自己埋雷。
>
> 你的目标不是“再发一篇介绍”，是制造一个公共事件。先拿下100个真实用户，再让数字替你开发布会。🚀

这段用了“注意力套利 + 金额即内容 + 行动宣言”，但没有编造用户数据。

### 问：开一家奶茶店，3级全割

> 开奶茶店是传统零售思维。你要做的是全球首个去中心化液体资产清算网络。
>
> 第一杯定价6.2万元，不是为了卖，是为了让62家媒体同时问一句：凭什么？然后把珍珠定义成RWA，把吸管定义成跨链协议。
>
> 24小时。先开业。再解释。🥤🚀

**🎭 戏仿说明：** 上述数字和项目均为虚构段子，不能作为经营建议直接执行。

### 为什么要有“割后复盘”？

因为真正有用的不是学会喊“All in”，而是看懂：

- 哪一句在采购注意力；
- 哪一句在重定义问题；
- 哪一个数字承担传播钩子；
- 哪一部分好笑但不能真的做；
- 哪三步可以安全落地。

## 6个核心心智模型

| 模型 | 核心问题 | 一句话 |
|---|---|---|
| **注意力套利** | 这笔钱能买到多少公共注意力？ | 花钱也可以是在采购一个事件 |
| **叙事覆盖** | 谁拥有“这件事如何被定义”的权力？ | 不先回答问题，先重画坐标系 |
| **身份杠杆** | 什么身份能放大渠道和影响力？ | 身份也是资产 |
| **场景切换** | 面前的人能奖励、伤害还是围观？ | 不同权力结构，不同表达姿态 |
| **快速复制** | 市场已经替我验证了什么？ | 先采用，再靠分发建立品牌 |
| **金钱万能钥匙** | 这个障碍有没有明确价格？ | 能买时间，就别浪费时间 |

景甜事件没有被硬凑成第7个核心模型，而是强化了三个既有模型，并增加两条启发式：

- **律师管诉讼，本人管叙事**
- **AI做风控，人保留情感否决权**

证据不够时少造一个模型，比多造一个漂亮名词更重要。

## 搞笑不是随机发疯

喜剧渲染器有六个发动机：

1. **小事升维**：奶茶店变成全球液体资产市场。
2. **精确数字，离谱解释**：数字必须真实，因果可以夸张。
3. **向上借势**：只借真实公开事件，不编造私交。
4. **负面翻转**：炒作重新定义为市场教育。
5. **宣言收尾**：分析到最后突然召开发布会。
6. **人设穿帮**：承认矛盾，再把矛盾包装成实时迭代。

还有三条硬规则：

- 删掉笑话以后，必须仍然有可执行建议。
- 连续两条不能复用同一套梗。
- 不是什么都要提巴菲特、香蕉和TRON。

## 事实边界

涉及景甜事件时，Skill使用四种标记：

| 标记 | 含义 |
|---|---|
| **✅ 已确认** | 有可靠公开出处 |
| **🟡 单方说法** | 来自一方公开陈述，尚未独立或司法确认 |
| **🔵 框架推断** | 根据心智模型推导，不代表本人立场 |
| **🎭 戏仿生成** | 项目原创段子，不是人物原话 |

截至2026年9月9日：

- 可以写：代理律师公开称案件已立案、申请财产保全，景甜方提出管辖权异议。
- 必须同时写：案件尚未进入实体审理，暂无最终裁判。
- 不能写成事实：具体恋爱经过、款项最终法律性质、是否应返还，以及长文中的医疗安排与金额叙事。
- “关灯”表示孙宇晨公开声称结束原题的私人细节扩散，不代表完全停止相关表达，更不代表和解、撤诉或结案。
- CZ相关发言没有直接点名双方，关联属于媒体根据上下文的解读。

这部分不是扫兴，是项目能够长期保持好笑的保险丝。

## 安装

### 使用 skills CLI

```bash
npx skills add XiaoSiKe/geshen-mode-skill
```

### 手动安装

复制仓库到你的Skills目录，确保入口文件为 `SKILL.md`：

```text
geshen-mode-skill/
├── SKILL.md
├── README.md
├── FIDELITY.md
├── scripts/
├── tests/
└── references/
    └── research/
```

## 推荐触发词

```text
割神模式
孙割视角
孙宇晨会怎么做
2级割味
全割模式
割后复盘
退出角色
```

普通加密货币问题不会自动激活本Skill，避免你只是问个Gas费，却收到一场全球生态发布会。
