有人花620万美元买下一根香蕉，有人用约6000字解释一段感情，再用两个字——“关灯”——宣布收束。到了9月7日，长访又上线了。

灯确实关了，采访麦还亮着。

这不是一款教你“收割”的Skill，也不是给AI换上西装后反复喊“All in”。**割神模式（孙宇晨Skill）**研究的是一套更值得拆解、也更需要警惕的公开行为逻辑：钱如何购买注意力，身份如何放大分发，争议如何被重新命名，以及高曝光策略最后由谁承担成本。

幽默是入口，模型是正餐，证据负责买单。

## 它到底能做什么

你可以把它当作一位“懂热搜，也懂止损”的策略顾问：先把事实和单方说法分开，再选择孙宇晨式模型，最后给出可以执行、可以衡量、也可以叫停的方案。

| 任务 | 它会追问什么 | 最终交付 |
|---|---|---|
| 产品发布 | 什么真实反常点值得传播？ | 24—72小时动作、转化指标、止损线 |
| 内容营销 | 热点与产品之间有真实关系吗？ | 选题、标题、借势动作、反噬风险 |
| 品牌定位 | 哪个身份能放大可信度与分发？ | 定位、合作对象、证据要求 |
| 危机沟通 | 应该回应、沉默，还是换轨？ | 事实边界、受众矩阵、退出条件 |
| 创业决策 | 什么可以复制，什么必须原创？ | 最小实验、资源配置、判断标准 |
| 策略复盘 | 真正有效的是模型还是表演？ | 因果链、可复用动作、失败代价 |

直接这样问：

```text
用割神模式分析：我的产品为什么有曝光、没转化？
2级微割，给这次发布设计一个注意力钩子和止损线。
全割模式，把早餐摊开业做成一个公共事件，但别瞎编数字。
这场公关该回应、沉默还是换轨？按受众分别判断。
把刚才的回答做一次割后复盘：哪些是模型，哪些只是段子？
```

普通币价、Gas费、TRON技术或人物履历查询不会自动入戏。毕竟不是每个问题都值得上热搜，有些问题配得上一个正常答案。

## 6个核心模型

| 模型 | 一句话判断 |
|---|---|
| 注意力套利 | 这项投入能购买多少**可转化**的公共注意力？ |
| 叙事覆盖 | 谁正在定义问题，新定义是否仍尊重事实？ |
| 身份杠杆 | 哪个真实身份或关系能放大影响力？ |
| 场景切换矩阵 | 面对大众、媒体、同行与司法，应采用什么姿态？ |
| 快速复制 + 品牌溢价 | 市场验证了什么，差异必须建在哪里？ |
| 金钱万能钥匙 | 哪个障碍能用资本换时间，哪个绝对不能？ |

详细证据、局限和启发式见 [core-models.md](references/core-models.md)。这里不把“说得响”误认成“说得对”，也不把曝光量误认成信用余额。

## 它怎么工作

```text
证据层：查人物、数字、时间、司法状态和原始出处
   ↓
决策层：选择1—3个模型，形成因果判断、动作和止损
   ↓
表达层：按0—4级控制幽默、戏仿和复盘深度
```

现实争议统一分成四层：

- ✅ **已确认**：可靠公开来源支持的行为或程序状态；
- 🟡 **单方说法**：当事人、代理人或利益相关方的公开陈述；
- 🔵 **框架推断**：根据模型得出的解释，不冒充本人动机；
- 🎭 **戏仿生成**：项目原创表达，不伪装成人物原话。

模式可以提高割味，不能降低事实标准。无法核验时，Skill会降级说明边界，而不是请段子替证据补考。

## 五档割味

| 等级 | 模式 | 适用情况 |
|---|---|---|
| 0 | 退出 | 恢复普通助手，不残留人设 |
| 1 | 正常分析 | 研究、事实判断、风险评估 |
| 2 | 微割，默认 | 专业建议为主，少量幽默 |
| 3 | 全割 | 高辨识度戏仿，但策略必须完整 |
| 4 | 割后复盘 | 先输出，再拆模型、动作、代价和反证 |

## 景甜事件：最新案例怎么读

这一案例只用于研究**注意力、叙事退出、AI决策边界和私人事件公共化**，不用于替法院断案，也不拿私人身体细节做笑料。

- 8月27日，孙宇晨代理律师公开称案件已立案并申请财产保全；景甜方提出管辖权异议。公开报道显示，案件尚未进入实体审理，没有最终裁判。[程序报道](https://www.thepaper.cn/newsDetail_forward_33962837)
- 孙宇晨发布《我的女友景甜》长文；景甜及工作室公开回应。双方对关系、款项和动机的描述都属于各自立场，不是法院认定。
- 8月29日，孙宇晨以“关灯”表达收束，并称其余交给法院。这不代表和解、撤诉或结案。
- 9月6日，他再次接受长篇采访；9月7日采访公开。他继续主张款项属于彩礼、表示和解通道未关闭，并称今后不在社交平台披露案件细节。[9月7日采访](https://www.sina.cn/news/detail/5340457894938117.html)

专业的读法不是“他到底有没有关灯”，而是检查四件事：**退出了哪个话题、在哪个渠道退出、由谁继续发声、司法状态有没有变化。**

本案例的结论是：私人细节的声明性退出，不等于媒体叙事退出，更不等于司法程序结束。用割神模式的话说：灯可以关，时间线不能断电。

完整时间线、单方说法和禁区见 [jingtian-2026.md](references/cases/jingtian-2026.md)。

## 安装

确保本机可运行 Node.js 与 `npx`。在项目中安装，让CLI自动识别当前Agent：

```bash
npx skills add XiaoSiKe/geshen-mode-skill --skill geshen-mode -y
```

希望所有项目都能使用，就全局安装：

```bash
npx skills add XiaoSiKe/geshen-mode-skill --skill geshen-mode -g -y
```

检查是否安装成功：

```bash
npx skills list
```

列表中看到 `geshen-mode` 后，新开一个会话，直接说“用割神模式分析这次发布”即可。更新已安装版本使用 `npx skills update`。

也可以从 [Releases](https://github.com/XiaoSiKe/geshen-mode-skill/releases) 下载纯Skill压缩包。压缩包只包含入口、UI元数据、图标与运行所需references，不夹带测试、CI或“买香蕉的预算申请表”。
