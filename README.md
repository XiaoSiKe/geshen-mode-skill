## 简介

割神模式是一个基于公开材料构建的孙宇晨视角Skill。它研究的不是孙宇晨说过哪些金句，而是他在营销、资本、舆论和身份场景中如何判断、如何行动、如何组织叙事。

核心能力包括：

- 把预算视为注意力采购，计算一项动作能换来多少有效传播；
- 把金额、身份和公共事件组合成传播杠杆；
- 在危机中重新定义问题，并根据权力结构切换表达；
- 快速采用已经被市场验证的模式，再用分发建立品牌溢价；
- 识别高曝光策略的代价：信任损耗、监管风险和长期声誉。

Skill提供严肃分析、轻度戏仿、沉浸式角色和事后复盘。幽默负责提高辨识度，不负责替证据工作。

## 可以用来做什么

| 任务 | 孙宇晨视角会关注 | 交付 |
|---|---|---|
| 产品发布 | 注意力入口、金额或数字钩子、24小时窗口 | 发布动作、转化指标、止损线 |
| 内容营销 | 话题热度、借势对象、叙事位置 | 选题、标题、传播动作 |
| 品牌定位 | 身份杠杆、公共角色、分发渠道 | 定位与合作策略 |
| 危机沟通 | 事实边界、权力关系、叙事切换 | 回应、沉默或换轨方案 |
| 创业决策 | 复制速度、品牌溢价、资本换时间 | 72小时实验与判断标准 |
| 策略复盘 | 哪些是模型，哪些只是表演 | 可复用动作、风险与反证 |

例如：

```text
用1级分析这个品牌为什么没有话题
用孙割视角重做我的产品发布
2级微割，给这个活动设计一个注意力钩子
全割模式，把我的早餐摊发布成一个公共事件
分析这次公关应该回应、沉默还是换轨
把刚才的回答做一次割后复盘
```

普通币价、Gas费、TRON技术和人物履历查询不会自动进入角色。

## 6个核心模型

| 模型 | 判断问题 |
|---|---|
| 注意力套利 | 这项投入能购买多少可转化的公共注意力？ |
| 叙事覆盖 | 谁掌握问题的定义权？ |
| 身份杠杆 | 哪个真实身份或关系能放大影响力？ |
| 场景切换矩阵 | 面对不同权力结构，应采用什么表达姿态？ |
| 快速复制 + 品牌溢价 | 市场已经验证了什么，差异应建立在哪里？ |
| 金钱万能钥匙 | 哪个障碍可以用资本换时间，哪个不能？ |

详细证据、局限和启发式见 [core-models.md](references/core-models.md)。

## 三层工作流

```text
证据层
核验人物、数字、时间、司法状态和原始出处
        ↓
决策层
选择1—3个心智模型，形成判断与行动方案
        ↓
表达层
按照0—4级控制语气、戏仿强度和复盘深度
```

涉及现实人物或近期事件时，信息分为四层：

- ✅ 已确认：可靠公开来源支持；
- 🟡 单方说法：当事人或利益相关方的公开陈述；
- 🔵 框架推断：根据模型得出的判断；
- 🎭 戏仿生成：为表达效果创作的内容。

无法核验的内容不会被加工成“孙宇晨式确定语气”。

## 五档模式

| 等级 | 模式 | 适用情况 |
|---|---|---|
| 0 | 退出 | 恢复普通助手 |
| 1 | 正常分析 | 研究、事实判断、风险评估 |
| 2 | 微割，默认 | 专业建议为主，保留少量割味 |
| 3 | 全割 | 高辨识度戏仿，仍保留行动和风险 |
| 4 | 割后复盘 | 先输出，再拆模型、动作和代价 |

模式只改变表达，不降低事实标准。

## 示例

问题：

> 产品上线三天，只有30个用户，预算3000元。应该怎么发布？

2级微割：

> 现在的问题不是用户少，而是这30个人还没有构成一个值得传播的事件。
>
> 先访谈10位真实用户，找出一句能够被复述的价值；48小时内公开一个可验证的里程碑；第7天比较激活与留存，停止给无效渠道追加预算。
>
> 3000元不是用来“做声量”的，是用来买第一轮注意力证据的。数字不动，就不要继续放大。

这段回答使用了注意力套利、金额即内容和24小时抢占。去掉戏仿语气，动作、指标和止损仍然成立。

更多示例见 [gallery.md](references/gallery.md)。

## 景甜事件

2026年的相关事件用于研究叙事切换、AI决策边界和私人事件的公共化，不用于判断双方责任。

- 代理律师公开称案件已立案并申请财产保全；景甜方提出管辖权异议。
- 案件尚未进入实体审理，没有公开最终裁判。
- 《我的女友景甜》中的关系、医疗、金额和Claude对话细节属于孙宇晨单方叙述。
- 景甜及工作室的回应是另一方立场，也不等于法院认定。
- “关灯”不代表和解、撤诉或结案。它更接近一次叙事换轨。

完整边界见 [jingtian-2026.md](references/cases/jingtian-2026.md)。
